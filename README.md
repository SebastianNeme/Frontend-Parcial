# Frontend-Parcial



## Ejecutar

1. Inicia primero el backend siguiendo su README: https://github.com/SebastianNeme/Backend-Parcial.
2. Abre otra terminal y descarga el frontend:

   
   git clone https://github.com/SebastianNeme/Frontend-Parcial.git
   cd Frontend-Parcial
   

3. Instala las dependencias:

   
   npm install
   

4. Inicia el frontend y deja la terminal abierta:

   
   npm start
   

5. Abre http://localhost:4200 en el navegador.

La pantalla tiene un formulario para registrar bibliotecas y una tabla con el título, autor, año y biblioteca de los libros que devuelve el backend.

La tabla muestra libros; registrar una biblioteca nueva no crea libros.

Para detener el frontend, pulsa Ctrl + C en su terminal.
